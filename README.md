# 职场日语表达助手

这是一个面向中文母语者的日本职场日语表达辅助工具。

用户输入想表达的中文，再选择对象、使用场景、礼貌度和长度 / 形式。工具会生成一段可以复制到 ChatGPT 的提示词，让 ChatGPT 在保留原意的前提下，整理成自然、得体、不过度卑微的日本职场日语。

## 在线使用

[打开职场日语表达助手](https://radishzzzz.github.io/japanese-workplace-prompt-app/)

## 适用场景

- Slack / Teams 日常沟通
- 上司或团队进度报告
- 客户和公司外部邮件
- 口头报告或朝会发言
- 朝会模板填写
- 文档和会议记录

## 使用方法

1. 输入想表达的中文。
2. 选择沟通对象和使用场景。
3. 调整礼貌度和长度 / 形式。
4. 点击“生成提示词”。
5. 点击“复制提示词”。
6. 切换到 ChatGPT，粘贴并发送。

工具会从中文原文判断报告、确认、商量、请求、道歉等意图，不需要用户再次选择“目的”。

## 产品原则

- 减少中文直译感。
- 根据日本职场语境调整表达。
- 保留原意，不擅自增加事实、请求、情绪或下一步。
- 自然、礼貌，但不堆砌敬语或过度卑微。
- “短句 / 条目”“一句话”“1–2句”“2–3句”“4–5句”对应不同的最终输出形式。

## 隐私注意

这个网页本身不调用 AI，也不主动把输入上传到项目服务器。复制到 ChatGPT 前，请把客户名、项目名、公司机密等敏感信息替换成通用称呼。

## 本地运行

当前版本是静态网页，可以使用 VS Code Live Server 打开 `index.html`，也可以部署到 GitHub Pages。

主要文件：

- `index.html`：页面结构和选项。
- `style.css`：响应式布局和样式。
- `app.js`：提示词生成、复制和历史记录。
- `manifest.webmanifest`：安装配置。
- `sw.js`：离线缓存。
