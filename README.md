# 职场日语表达助手

这是一个面向中文母语者的日本职场日语表达辅助工具。

用户输入想表达的中文，再选择对象、使用场景、礼貌度和长度 / 形式。工具会生成一段可以复制到 ChatGPT 的提示词，让 ChatGPT 在保留原意的前提下，提供两种自然、得体、不过度卑微的日本职场日语表达，方便用户自行选择。

## 在线使用

[打开职场日语表达助手](https://radishzzzz.github.io/japanese-workplace-prompt-app/)

## 适用场景

- Slack / Teams 日常沟通
- 上司或团队进度报告
- 客户和公司外部邮件
- 口头报告或朝会发言
- 朝会模板填写
- 文档和会议记录

## 使用方法

1. 输入想表达的中文。
2. 选择沟通对象和使用场景。
3. 调整礼貌度和长度 / 形式。
4. 点击“生成并复制提示词”。如果浏览器阻止复制，可在结果区手动复制。
5. 切换到 ChatGPT，粘贴并发送。

对象、场景、礼貌度和长度 / 形式会记住上一次的选择。页面上的三个常用示例可以自定义：先写好中文并调整设置，展开“自定义这 3 个示例”，选择位置、修改名称并保存；也可以单独恢复默认示例。点击示例会替换当前中文和四项设置。

网页本身不对报告、确认、商量、请求、道歉等意图进行分类，也不需要用户再次选择“目的”。网页会根据所选沟通条件和中文原文生成提示词，后续由 ChatGPT 根据中文原文理解具体沟通意图。

## 产品原则

- 减少中文直译感。
- 根据日本职场语境调整表达。
- 保留原意，不擅自增加事实、请求、情绪或下一步。
- 自然、礼貌，但不堆砌敬语或过度卑微。
- “短句 / 条目”“一句话”“1–2句”“2–3句”“4–5句”对应不同的最终输出形式。
- 每次提供两种意思一致、措辞略有差别的日语候选；长度要求分别适用于每一种候选。

## 隐私注意

这个网页本身不调用 AI，也不主动把输入上传到项目服务器。最近记录、自定义示例和上次选择保存在当前设备的浏览器中；自定义示例可能长期保留你写入的中文。复制到 ChatGPT 前，请把客户名、项目名、公司机密等敏感信息替换成通用称呼。

## 本地运行

当前版本是静态网页，可以使用 VS Code Live Server 或其他静态服务器打开 `index.html`，也可以部署到 GitHub Pages。目前没有稳定统一的启动、测试或构建命令。

主要文件：

- `index.html`：页面结构和选项。
- `style.css`：响应式布局和样式。
- `app.js`：提示词生成、复制和历史记录。
- `manifest.webmanifest`：安装配置。
- `sw.js`：离线缓存。
