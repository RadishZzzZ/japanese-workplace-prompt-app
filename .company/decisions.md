# 项目决定

## JWP-DEC-001：保持静态 PWA 为默认架构

- 状态：accepted
- 日期：当前规则，原始决定日期待确认
- 决定：默认保持前端静态文件、GitHub Pages 兼容和无需项目服务器的结构。
- 后果：引入依赖、后端、API、成本、密钥或隐私变化前必须先说明权衡。
- 来源：`AGENTS.md`

## JWP-DEC-002：保留核心输入维度

- 状态：accepted
- 日期：当前规则，原始决定日期待确认
- 决定：除非任务明确要求重设计，否则保留沟通对象、使用场景、礼貌度和长度/形式的核心结构。
- 后果：一般优化不得擅自删除或替换这些维度。
- 来源：`AGENTS.md`

## JWP-DEC-003：不设置目的选择器，由 ChatGPT 理解中文原文意图

- 状态：accepted
- 日期：当前规则，原始决定日期待确认
- 决定：网页本身不执行沟通意图分类，也不重新引入必选的目的或模式选择器。网页根据用户选择和中文原文生成 Prompt，后续由 ChatGPT 根据中文原文理解具体沟通意图。
- 后果：项目文档不得把 ChatGPT 的意图理解能力写成网页自身能力；Prompt 生成逻辑应保留原意，不擅自增加事实、请求、情绪或下一步。
- 来源：`README.md`、`AGENTS.md`

## JWP-DEC-004：网页本身不调用 AI

- 状态：accepted
- 日期：当前产品说明，原始决定日期待确认
- 决定：当前网页自身不调用 AI，也不主动把输入上传到项目服务器；用户手动复制 Prompt 到 ChatGPT。
- 后果：任何 API 集成都属于会改变隐私、安全、成本和部署边界的大改动。
- 来源：`README.md`
